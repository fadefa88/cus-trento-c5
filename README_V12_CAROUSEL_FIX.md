# V12 carousel fix

- Il titolo “Prossime partite” è su una riga propria.
- Le card tornano in carousel orizzontale full-width, non in griglia a capo.
- Frecce laterali ripristinate e nascoste automaticamente a inizio/fine carousel.
- Nessun limite massimo alle card: vengono mostrate tutte le partite future/presenti da CMS.
- Nessuna ombra o animazione hover sulle card.
- Su mobile il carousel resta orizzontale a singola card larga, senza frecce laterali ingombranti.
